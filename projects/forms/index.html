Formulário Interativo

Contexto

Este projeto foi desenvolvido como parte do meu aprendizado em front-end, com o objetivo de criar um formulário funcional e responsivo. A ideia era praticar a manipulação de elementos HTML, estilização com CSS e validações básicas com JavaScript, simulando um caso real de coleta de informações de usuários.

Desafio

O desafio principal foi construir um formulário que fosse:

  • Intuitivo e fácil de usar
  • Visualmente agradável e consistente
  • Validado em tempo real para evitar erros de preenchimento

Solução

A solução foi implementada utilizando:

  • HTML: Estrutura semântica para os campos de entrada, labels e botões.
  • CSS: Estilização moderna, com foco em responsividade e usabilidade.
  • JavaScript: Validações de campos obrigatórios, feedback imediato ao usuário e lógica de envio.

Resultado

O formulário está disponível online e pode ser acessado aqui. Ele demonstra minha capacidade de integrar diferentes tecnologias front-end em um projeto funcional e bem estruturado.

Versão desktop

Aprendizados

  • Importância da semântica no HTML para acessibilidade.
  • Uso de CSS para criar uma experiência visual agradável e responsiva.
  • Aplicação de JavaScript para melhorar a interação e prevenir erros de usuário.
