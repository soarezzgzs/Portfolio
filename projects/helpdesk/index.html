HelpDesk

⭐ Projeto Destaque • Desafio Final da Formação Full Stack Rocketseat

Contexto

O HelpDesk foi desenvolvido como projeto final da formação Full Stack da Rocketseat, com o objetivo de simular um sistema real de gerenciamento de chamados técnicos. A plataforma permite que clientes solicitem atendimento, técnicos realizem os atendimentos e administradores gerenciem toda a operação através de um painel centralizado. O frontend foi construído utilizando React, TypeScript, TailwindCSS e Vite, proporcionando uma interface moderna, responsiva e de alta performance. O backend foi desenvolvido com Node.js, Express, Prisma ORM e PostgreSQL, garantindo segurança, escalabilidade e organização da aplicação. O sistema foi disponibilizado em produção através da Vercel (frontend) e Render (backend e banco de dados), simulando um cenário corporativo próximo ao mercado real.

Desafio

Os principais desafios encontrados durante o desenvolvimento foram:

  • Implementar autenticação segura utilizando JWT e controle de acesso baseado em perfis.
  • Criar permissões específicas para três tipos de usuários: Cliente, Técnico e Administrador.
  • Desenvolver uma estrutura escalável capaz de suportar múltiplos fluxos de atendimento.
  • Garantir comunicação eficiente entre frontend e backend utilizando API REST.
  • Implementar upload de avatar e atualização de perfil mantendo segurança e integridade dos dados.
  • Organizar o projeto utilizando boas práticas de arquitetura, componentização e separação de responsabilidades.

Solução

A solução foi implementada utilizando:

  • React + TypeScript: construção de uma interface moderna, tipada e componentizada.
  • React Hook Form + Zod: validação de formulários com segurança e praticidade.
  • TailwindCSS: estilização responsiva seguindo a abordagem Mobile First.
  • Node.js + Express: criação das rotas e regras de negócio da aplicação.
  • Prisma ORM: gerenciamento do banco de dados de forma segura e produtiva.
  • PostgreSQL: armazenamento de dados em ambiente de produção.
  • JWT + Middleware de Autenticação: proteção de rotas e controle de acesso.
  • Vercel e Render: deploy completo da aplicação em ambiente produtivo.

Resultado

O sistema está totalmente funcional e demonstra minha capacidade de desenvolver aplicações Full Stack completas, desde a interface até a infraestrutura de deploy.

  • Cadastro e autenticação de usuários.
  • Acesso baseado nos perfis Cliente, Técnico e Administrador.
  • Criação, acompanhamento e gerenciamento de chamados.
  • Atualização de status dos atendimentos.
  • Gerenciamento de técnicos e clientes.
  • Cadastro e administração de serviços.
  • Upload e gerenciamento de avatar.
  • Alteração de senha e edição de perfil.
  • Aplicação responsiva para mobile, tablet e desktop.
  • Deploy completo em ambiente de produção.

Aprendizados

  • Autenticação utilizando JWT em aplicações Full Stack.
  • Controle de acesso baseado em permissões e perfis de usuário.
  • Integração entre React e APIs REST construídas com Express.
  • Modelagem de banco de dados utilizando Prisma ORM e PostgreSQL.
  • Validação de dados com Zod e React Hook Form.
  • Upload de arquivos e gerenciamento de imagens de perfil.
  • Deploy profissional utilizando Vercel e Render.
  • Estruturação de aplicações escaláveis utilizando TypeScript em todo o projeto.
