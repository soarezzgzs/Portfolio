Sistema de reembolso

Contexto

Este projeto foi desenvolvido como parte de um desafio prático da Rocketseat, com o objetivo de criar uma aplicação simples e funcional para gerenciamento de uma lista de compras. A ideia era aplicar conceitos de manipulação de DOM, armazenamento local e interação com o usuário em um cenário cotidiano.

Desafio

O desafio consistia em:

  • Criar uma interface intuitiva para adicionar e remover itens da lista.
  • Garantir que os dados fossem persistidos mesmo após fechar o navegador.
  • Manter a aplicação responsiva e fácil de usar em diferentes dispositivos.

Solução

A solução foi implementada utilizando:

  • HTML: Estrutura semântica para os campos de entrada e lista de itens.
  • CSS: Estilização responsiva e clara, garantindo boa experiência visual.
  • JavaScript: Lógica para adicionar, remover e armazenar itens no localStorage, mantendo a lista disponível em sessões futuras.

Resultado

A aplicação está disponível online e pode ser acessada aqui. Ela demonstra minha capacidade de transformar um desafio prático em uma solução funcional, aplicando conceitos de persistência de dados e interação com o usuário.

Aprendizados

  • Como manipular o DOM para criar e atualizar elementos dinamicamente.
  • Uso do localStorage para persistência de dados em aplicações front-end.
  • Importância da responsividade e da simplicidade em interfaces voltadas para o dia a dia.
