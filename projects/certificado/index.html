Gerador de Certificados

Contexto

Este projeto foi desenvolvido durante um curso da Rocketseat, com foco em Angular e TypeScript, aplicando conceitos de armazenamento local e geração dinâmica de documentos.

Desafio

O desafio principal era:

  • Criar uma interface intuitiva para inserção de dados (nome, curso, data etc.).
  • Gerar certificados dinâmicos com base nas informações fornecidas.
  • Permitir que os certificados fossem armazenados e recuperados posteriormente, sem necessidade de backend.

Solução

A solução foi implementada utilizando:

  • Angular: Framework para estruturar o projeto, organizar componentes e facilitar a manutenção.
  • TypeScript: Tipagem estática para maior segurança e clareza no código.
  • localStorage: Armazenamento direto no navegador, garantindo que os certificados criados possam ser salvos e acessados novamente.

Resultado

O gerador está disponível online e pode ser acessado aqui. Ele demonstra minha capacidade de criar aplicações completas com Angular, integrando lógica de negócio, interface e persistência de dados.

Aprendizados

  • Como estruturar um projeto em Angular com componentes reutilizáveis.
  • A importância do localStorage para aplicações sem backend.
  • Boas práticas de tipagem e organização de código com TypeScript.
