Vintage Vinyl

Contexto

Este projeto foi desenvolvido como um treino prático, com o objetivo de criar um e-commerce voltado para a venda de discos de vinil. Além de aplicar conceitos de desenvolvimento web, o projeto tem um valor pessoal, já que foi pensado para o meu pai, que é apaixonado por música e coleciona vinis.

Desafio

O desafio principal era:

  • Estruturar um catálogo de produtos com vinis organizados por categorias.
  • Criar páginas de produto com informações detalhadas.
  • Garantir uma interface responsiva e agradável para diferentes dispositivos.

Solução

A solução foi implementada utilizando:

  • HTML, CSS e JavaScript para a interface e interatividade.
  • Estrutura modular para facilitar futuras expansões.

Resultado

O projeto funciona como um e-commerce completo em ambiente de treino, permitindo:

  • Navegar por um catálogo de vinis organizados por categorias.
  • Visualizar detalhes de cada produto, incluindo descrição e preço.

Aprendizados

  • Estruturação de um e-commerce do zero.
  • Organização de produtos e categorias.
  • Experiência prática em pensar na usabilidade de um site de vendas.
