Sistema de reembolso

Contexto

Este projeto foi desenvolvido como parte de um desafio prático da Rocketseat, com o objetivo de criar uma aplicação que simulasse um sistema de solicitação de reembolso. O foco foi aplicar conceitos de front-end, usabilidade e organização de componentes em um cenário próximo ao corporativo.

Desafio

O desafio principal era:

  • Criar uma interface clara e profissional para solicitação de reembolso.
  • Garantir responsividade e boa experiência de uso em diferentes dispositivos.
  • Estruturar o código de forma organizada e escalável.

Solução

A solução foi implementada utilizando:

  • HTML: Estrutura semântica para formulários e elementos da interface.
  • CSS: Estilização moderna e responsiva, com foco em clareza visual.
  • JavaScript: Lógica para manipulação dos dados e interação com o usuário.

Resultado

O sistema está disponível online e pode ser acessado aqui. Ele demonstra minha capacidade de transformar um desafio prático em uma aplicação funcional, aplicando conceitos aprendidos e adaptando-os para um caso realista.

Aprendizados

  • Como estruturar interfaces voltadas para uso corporativo.
  • Importância da consistência visual e da experiência do usuário.
  • Aplicação de boas práticas de organização de código e responsividade.
