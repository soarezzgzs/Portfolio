Vinil tracker

Contexto

Este projeto foi desenvolvido com o objetivo de criar uma aplicação fullstack que permita aos usuários gerenciar suas coleções de discos de vinil. A plataforma oferece cadastro e login, CRUD completo de vinis e estatísticas detalhadas da coleção, como quantidade total, valor acumulado, artista mais frequente e disco mais caro. O frontend foi construído em React com TailwindCSS, garantindo uma interface moderna e responsiva. Para visualização dos dados, foram implementados gráficos interativos com Chart.js. No backend, a API foi desenvolvida em Node.js + Express, utilizando Knex para manipulação de banco de dados. Em desenvolvimento, o projeto usa SQLite, enquanto em produção utiliza PostgreSQL hospedado no Render. O deploy foi realizado com Vercel (frontend) e Render (backend e banco). Esse projeto se destaca pela integração completa entre frontend, backend e banco de dados, além da possibilidade de compartilhar a coleção via link público. Ele demonstra habilidades em desenvolvimento fullstack, deploy em nuvem e apresentação de dados de forma clara e interativa.

Desafio

O desafio principal era:

  • Integração frontend ↔ backend: garantir que as rotas da API estivessem bem definidas e que o React consumisse os dados corretamente, evitando problemas de tipagem e comunicação.
  • Banco de dados em ambientes diferentes: usar SQLite em desenvolvimento e PostgreSQL em produção exigiu ajustes nas queries e configuração do Knex para suportar ambos.
  • eploy em múltiplos serviços: configurar Vercel (frontend) e Render (backend + banco) trouxe desafios de variáveis de ambiente e conexões seguras.
  • Manipulação de dados para gráficos: transformar dados brutos em informações úteis para o Chart.js, lidando com casos como soma numérica vs concatenação de strings e agrupamento por artista.
  • Autenticação e compartilhamento público: implementar login seguro e ao mesmo tempo permitir links públicos exigiu atenção para não comprometer a segurança dos dados privados.

Solução

A solução foi implementada utilizando:

  • Node.js + Express: utilizados para construção do servidor e definição das rotas da API, garantindo comunicação eficiente entre frontend e backend.
  • Knex.js: escolhido como query builder para facilitar a manipulação do banco de dados e manter o código mais organizado e escalável.
  • SQLite (desenvolvimento): banco leve e simples para testes locais, permitindo desenvolvimento rápido sem necessidade de infraestrutura complexa.
  • PostgreSQL (produção): banco robusto e confiável, hospedado no Render, garantindo persistência e performance em ambiente real.
  • React: framework para construção da interface do usuário, proporcionando uma experiência dinâmica e responsiva.
  • TailwindCSS: utilizado para estilização rápida e consistente, garantindo uma interface moderna e adaptável a diferentes dispositivos.
  • Chart.js: biblioteca para criação de gráficos interativos (Bar e Doughnut), permitindo visualização clara das estatísticas da coleção.
  • Vercel + Render: plataformas de deploy que possibilitaram colocar o frontend e backend em produção, simulando um ambiente real de aplicação.

Resultado

O sistema está disponível em ambiente de produção e demonstra minha capacidade de criar aplicações fullstack completas, integrando frontend, backend e banco de dados. Ele permite:

  • Cadastro e login de usuários.
  • CRUD de discos de vinil (adicionar, listar, editar e excluir).
  • Visualização de estatísticas da coleção (quantidade, valor total, artista mais frequente, disco mais caro).
  • Exibição de gráficos interativos (Bar e Doughnut) com Chart.js.
  • Compartilhamento público da coleção via link acessível sem login.

Aprendizados

  • Configuração de ambiente de produção com Vercel e Render.
  • Integração entre frontend (React) e backend (Node.js + Express).
  • Uso de Knex para manipulação de dados em diferentes bancos (SQLite e PostgreSQL).
  • Implementação de autenticação e compartilhamento público de dados.
  • Manipulação e visualização de dados com gráficos interativos usando Chart.js.
  • Estilização moderna e responsiva com TailwindCSS.
